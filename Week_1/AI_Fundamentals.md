# Brain Training 

Supervised learning trains a model using data that includes known answers or labels.

The model learns by comparing predictions to the ocrrected outputs and adjusting accordingly

Unsupervised learning is where a model learns from data without being given the correct answer

It identifies relationships and patterns within the data for itself

Reinforcement learning is where a model is incentivised to 'think correctly' by influence of reward/penalty given as numerical values

Training accuracy is the model tested against training images

validation accuracy is the model tested against held back images
